#+title: lattice gas automaton

- ~lga.janet~, Janet script that renders a video with ffmpeg
- ~lga.c~, C program compiled to WebAssembly

#+begin_src sh
make
#+end_src

Renders ~lga-2000.mp4~, a 600 frame video of a 1000 by 1000 cell
grid.

* Requirements

- Janet (tested with 1.42)
- ffmpeg with libx264

* Build

#+begin_src sh
make                  # render lga-2000.mp4 with default options
make help             # show all options
make check            # confirm janet and ffmpeg are installed
make clean            # remove the video and the wasm build
#+end_src

You can pass options through the ~LGA_FLAGS~ variable:

#+begin_src sh
make LGA_FLAGS="--seed 42 --gas 0.2" video
make LGA_FLAGS="--width 500 --height 500 --frames 300" video
#+end_src

* Sources

- Wikipedia pages "Lattice gas automaton" and "HPP model"
- Frisch, Hasslacher and Pomeau, 1986, which describes the
  hexagonal FHP variant that restores isotropy
